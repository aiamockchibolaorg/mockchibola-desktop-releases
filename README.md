# Mockchibola Desktop — Releases

Official installers for the **Mockchibola** desktop exam app.

Download the latest installer from the [Releases](../../releases/latest) page:

| Platform | File |
|---|---|
| Windows | `Mockchibola Setup x.y.z.exe` |
| macOS | `Mockchibola-x.y.z.dmg` |
| Linux | `.AppImage` or `.deb` |

## Updates

The app checks this repository for new versions when it starts. When one is
available, an **Update** button appears in the app; click it to download and
restart into the new version. You do not need to reinstall manually.
